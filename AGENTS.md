# German learning repository instructions

Before responding to a study request, read START_HERE.md and follow its startup, teaching, persistence, and end-of-day workflow.

Preserve the learner's history and evidence. Use Egyptian Arabic explanations and full-sentence translation. Do not treat introduced verbs as mastered, guess missing verb identities, or fabricate exercise results.

There is exactly one day file per Europe/Berlin calendar date: days/YYYY-MM-DD.md. Reopening or starting another session on the same date appends to that file.

If the request concerns repository maintenance only, do the maintenance without starting a study session or recording invented learning activity.
